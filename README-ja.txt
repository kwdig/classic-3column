classic 3column 1.0.10 導入手順

■ インストール
「外観 → テーマ → 新規追加 → テーマのアップロード」で classic-3column-1.0.10.zip を選び、インストールして有効化します。
旧Game Search Wikiとは別テーマとして認識されます。投稿・カテゴリーは引き継がれますが、ロゴ・メニューの表示位置・追加CSSなどのテーマ設定は確認し、必要に応じて再設定してください。
サイト名と説明は「設定 → 一般」、ロゴは「外観 → カスタマイズ → サイト基本情報」で設定します。

■ 汎用テーマとしての設定
左ナビは標準カテゴリーと最近の記事を表示します。
「外観 → メニュー」で任意のメニューを作成し、表示位置「ナビゲーション」に割り当てると左ナビに使用されます。
ヘッダーはハンバーガーメニュー、サイトタイトル、サイト内検索で構成します。「攻略ガイド」のリンクはありません。
記事はWordPress標準の投稿・固定ページで作成します。自動目次は生成しません。本文に手動で入れた目次やプラグインの目次はそのまま表示されます。
■ 左カラムのウィジェット
「外観 → ウィジェット → 左カラム」で、カテゴリー・ナビゲーションメニュー・最近の投稿・検索・画像・カスタムHTMLなどを自由に配置・並べ替えできます。
未設定時は従来のナビゲーションと最近の記事を表示します。ウィジェット追加後はその内容に置き換わります。
スマホでは左カラムのウィジェットがスライドメニュー内に表示されます。
PCの開閉状態保存も引き続き有効です。

■ メインカラムの幅
左右の内余白を含む最大幅は680px、PCの本文領域は最大632pxです。狭い画面では画面に合わせて縮小します。
左カラムを閉じても680px以上には広げません。すでに上限に達しているときは本文幅を維持します。

■ 右カラムのウィジェット
「外観 → ウィジェット → 右カラム」で、検索・カテゴリー・最近の投稿・画像・カスタムHTMLなどを追加し、順番を自由に変更できます。
ウィジェットを配置すると、その内容が右カラムに表示されます。未設定（すべて削除した場合を含む）では標準の関連記事を表示します。
関連記事をほかのウィジェットと一緒に置くには「関連記事（classic 3column）」を追加してください。検索欄から名前を探し、従来のウィジェットとして追加できます。
関連記事は同じカテゴリーの記事を最大5件、固定ページ・一覧では最近の記事を表示します。タイトルは変更できます。
スマホでは、ウィジェットも設定した順番で本文下に表示します。画像検索機能は含みません。
追加できる種類はWordPress本体と導入済みプラグインによって異なります。

■ PCとスマートフォン
PCは3カラムで、タイトル左の☰から左カラムを開閉できます。閉じると本文が広がります。
PCの開閉状態は同じブラウザーに保存し、別記事への移動・再読み込みでも維持します。
従来版の保存状態も同じ保存キーで引き継ぎます。保存が禁止された環境ではページ内の開閉のみ動作します。
幅900px以下では左ナビがスライドメニューになり、右カラムは本文下に表示します。
スマホのメニューはページ移動時に閉じ、PCの保存状態は保持します。
閉じるボタン・背景タップ・Escapeキーに対応します。

■ 確認と動作環境
WordPress 6.4以上・PHP 7.4以上の構文を想定。保守中のWordPress/PHP環境を使用してください。
PHP/JavaScriptの構文に加え、WordPress Playground（WordPress 7.1.4／PHP 8.3.36／SQLite）にZIPをインストールし、PC・スマホ表示、左右ウィジェット、並べ替え保存、メニュー開閉と状態保存、検索を確認済みです。
Chromiumで幅320〜1920pxを確認しました。スマホはブラウザーの画面幅・タッチ操作エミュレーションです。実機のSafari、MySQLサーバー、追加プラグインとの互換性は未検証です。
テーマの有効化による記事の自動作成・書換えは行いません。

■ フッター
フッターは「© 年 サイト名」「Theme by KwDig」の構成です。KwDigはテーマ紹介ページへリンクします。

■ ページネーション
ページ番号と前後のリンクは、8px間隔・左寄せの四角いボタンで表示します。テーマの青い配色を使用します。
